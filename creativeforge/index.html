IDEA / ASSET / PLAY

从生成走向可用。

将自然语言需求、模型能力、素材核验和试玩串成完整工作流；通过场景编译与规则约束检验素材在实际交互中的可用性。

前端 React / TypeScript，后端 FastAPI、REST 与 WebSocket；模型适配层支持本地、混合与云端运行路径。

02

六项核心产品能力。

面向真实创作场景的本地 AI、移动端、场景试玩、人工决策、质量验证与任务反馈。

01 / LOCAL INTELLIGENCE核心能力

本地 AI，进入真实工作流

支持 U2-Net 分割、Qwen 文本与 SDXL-Turbo/LCM 图像推理路径；显式区分本地、混合和云端模式。

让本地推理可用性、算力来源和云端调用可被检查。

02 / TABLET EXPERIENCE核心能力

从浏览器，走到平板现场

支持 Android WebView 壳、后端连接设置、下载支持、窗口避让与触控释放；完善原画放大及错误恢复。

支持手持设备实际创作、查看、试玩和接收文件。

03 / PLAYABLE CONTEXT核心能力

资产之外，有了可验证场景

支持场景工坊、跑酷平台编译、PVE 敌人与战役结构，以及关卡试玩入口。

把素材放进真实交互及关卡约束中检查。

04 / CREATOR IN CONTROL核心能力

提示词和动作，交还用户确认

增强候选需明确采用；超出本地能力的描述提示核对。加入逐帧朝向核验、动作隔离预览和人工采用/拒绝。

减少语义被静默改写、坏动作直接进入试玩的问题。

05 / EVIDENCE OVER SCORES核心能力

质量结论，有输入也有边界

支持真实媒体解码、帧检查、输入哈希及方法版本；将未评估、结构通过和引擎运行状态分开。补充 Godot 项目片段与独立构建工具。

让每条结论能追到素材和检查方法。

06 / WORKFLOW CONTINUITY核心能力

界面升级，长任务也更可读

支持任务流断连回退、错误/中断状态、动画缓存与真实参考图绑定；按生成、资产库、试玩重组导航和视觉表达。

提高创作过程的连续性，减少失联与上下文混淆。

01 / MODEL OUTPUT

模型输出仍需审核

本地原画可能有肢体或细节瑕疵；本地模式尚未部署 AI 动作视频模型。人工采用动作的决定与自动检查结果分别保存。

02 / ENGINE DELIVERY

引擎运行单独验收

已有资源包、Godot 项目片段与构建工具。结构检查不代表 Unity、Cocos、Godot 全部运行通过，本次未作三引擎实测结论。

03 / USER VALUE

商业结论留给真实用户

下一步通过需求符合率、审核后可用率和总制作耗时评价核心体验。当前没有已确认的付费、收入或独立用户验收结论。
